# CodeAlpha Internship – Task 4: Basic Chatbot

## Project Description
This is a simple rule-based chatbot developed using Python.

## Features
- Responds to greetings like Hello and Hi.
- Answers "How are you?"
- Tells its name.
- Responds to Thank you.
- Ends the conversation when the user types Bye.
- Gives a default response for unknown messages.

## Technologies Used
- Python
- VS Code

## Concepts Used
- Functions
- If-elif-else conditions
- While loop
- User input and output

## How to Run

1. Install Python.
2. Download `chatbot.py`.
3. Open the terminal in the project folder.
4. Run:

```bash
python chatbot.py
```
